Netflix Dataset Analysis & Power BI Dashboard

📌 Project Overview

This project focuses on analyzing the Netflix dataset to discover useful insights about movies and TV shows available on Netflix.

The dataset was cleaned and analyzed using Python and Pandas, and an interactive dashboard was created using Microsoft Power BI to visualize the results.

🎯 Objectives

- Analyze the Netflix movies and TV shows dataset.
- Clean and prepare the dataset for analysis.
- Explore movies and TV shows based on different categories.
- Analyze content by country, genre, release year, and rating.
- Identify useful trends and patterns.
- Create an interactive Power BI dashboard for data visualization.

🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- VS Code
- Microsoft Power BI
- CSV Dataset

🔄 Project Workflow

1. Data Collection

The Netflix dataset containing information about movies and TV shows was used for this project.

2. Data Cleaning

Python and Pandas were used to:

- Handle missing values
- Remove unnecessary columns
- Clean and transform data
- Check duplicate records
- Prepare the dataset for visualization

3. Exploratory Data Analysis

The cleaned dataset was analyzed to understand:

- Movies vs TV Shows
- Content by release year
- Popular genres
- Content ratings
- Countries producing Netflix content
- Distribution of movies and TV shows

4. Data Visualization

Charts were created using Python and an interactive dashboard was developed in Power BI.

📊 Power BI Dashboard

The Power BI dashboard provides an interactive view of the Netflix dataset.

It includes visualizations such as:

- Total Movies and TV Shows
- Movies vs TV Shows
- Content by Rating
- Content by Genre
- Content by Country
- Content by Release Year
- Interactive filters and slicers

🔍 Key Insights

The analysis helps understand:

- The distribution of movies and TV shows on Netflix.
- How Netflix content has changed over the years.
- Which genres have more content.
- Which countries contribute significantly to Netflix content.
- The distribution of different content ratings.
